# GreetMate — Minecraft 1.21.8 (Fabric) — v1.1.1

Клиентский Fabric-мод для персональных приветствий игроков при появлении в TAB.

## Использование

- Нажми **G**, чтобы открыть меню.
- Добавь ник игрока слева и выбери его.
- Справа добавь одно или несколько своих сообщений. Для каждого ника хранится отдельный список.
- Когда отслеживаемый игрок появляется в TAB, мод выбирает случайную фразу только из его списка. При наличии нескольких фраз один и тот же вариант не повторяется два раза подряд.
- Поиск фильтрует ники, цветная точка показывает онлайн-статус в TAB.
- Настройки хранятся в `config/greetmate.json`.
- Никаких готовых приветствий нет: сообщения отправляются только после того, как ты сам их добавишь.
- В тексте можно использовать `{player}` или `{name}` для подстановки ника; это необязательно.

## GitHub Actions

Workflow `.github/workflows/build.yml` собирает мод при push в `main`/ `master`, при Pull Request и вручную через **Actions → Build GreetMate → Run workflow**. Готовый JAR публикуется как artifact `GreetMate-Minecraft-1.21.8`.

Требования сборки: Java 21, Gradle 8.14.3, Minecraft 1.21.8, Fabric Loom.

## Установка

Скачай JAR из Artifacts завершённого запуска GitHub Actions и положи его в `.minecraft/mods`. Нужны Fabric Loader и Fabric API для Minecraft 1.21.8.

Это клиентский мод. Он отправляет сообщения от имени твоего аккаунта; сервер может ограничивать чат или антиспам. Отслеживание основано на обновлениях списка TAB, а не на расстоянии. Игроки, уже находившиеся в TAB при первоначальном подключении, не приветствуются.
