# GreetMate 2.0.2 — Minecraft 1.21.8 (Fabric)

![GreetMate icon](src/main/resources/assets/greetmate/icon.png)

Клиентский Fabric-мод для персональных приветствий с быстрым радиальным меню.

## Управление

- **G** — главное меню: добавление ников и редактирование их персональных фраз.
- **H** — колесо приветствий. Оба бинда можно изменить в **Настройки → Управление → GreetMate**.
- В колесе сначала выбери игрока, который сейчас виден в TAB, затем выбери одну из сохранённых для него фраз.
- Когда онлайн-игроков или сохранённых фраз нет, подсказки отображаются отдельно от центральной кнопки и не перекрываются ею.
- В главном меню выбери сохранённую фразу, измени её текст и нажми «Сохранить». Кнопка × отменяет редактирование.
- Колёсико мыши или стрелки влево/вправо переключают страницы, если игроков или фраз больше восьми.
- В круглом меню можно нажать правую кнопку мыши или ESC, чтобы вернуться назад. В центре колеса сообщений также есть кнопка «назад».

## Персональные сообщения

У каждого ника отдельный набор сообщений. Никаких предустановленных фраз нет. Можно использовать `{player}` или `{name}` для автоматической подстановки ника.

## Автоматические приветствия и кеш сессии

Автоприветствия остаются отдельной функцией и включаются/выключаются в главном меню. Мод запоминает, кому уже отправил автоматическое приветствие в рамках текущего подключения:
- повторные обновления TAB и скрытие/возврат игрока в TAB не создают повторное приветствие;
- при настоящем удалении игрока из списка профилей кеш для него сбрасывается;
- при подключении уже находящиеся в TAB игроки кешируются без приветствия, чтобы не отправлять старые сообщения пачкой.

## Сохранение настроек

Все ники и фразы по-прежнему хранятся в `config/greetmate.json`. Формат 1.x читается без потери существующих ников и сообщений. Настройка `enabled` из старой версии мигрирует в `autoGreetingEnabled`.

## Установка

### Что понадобится

- **Minecraft Java Edition 1.21.8**.
- **Java 21** — [скачать Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21).
- **Fabric Loader** — [официальный установщик Fabric](https://fabricmc.net/use/installer/). В установщике выбери Minecraft **1.21.8** и создай профиль Fabric.
- **Fabric API 0.136.1+1.21.8** — [скачать подходящую версию на Modrinth](https://modrinth.com/mod/fabric-api/versions?g=1.21.8&l=fabric). Нужен файл для Minecraft 1.21.8 и загрузчика Fabric.

### Установка мода

1. Скачай [последний GreetMate из GitHub Releases](https://github.com/doniel1488-code/GreetMate/releases/latest).
2. Помести `greetmate-*.jar` и файл Fabric API в папку `.minecraft/mods`.
3. Запусти Minecraft через профиль Fabric для версии **1.21.8**.

Если не знаешь, где находится папка `mods`, смотри [официальную инструкцию Fabric](https://docs.fabricmc.net/players/installing-mods).

GreetMate — клиентский мод: он отправляет выбранный текст в обычный чат от имени твоего аккаунта. Серверные ограничения чата и антиспам продолжают действовать.
