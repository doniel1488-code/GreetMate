# GreetMate 2.0.0

- Добавлено радиальное колесо приветствий на отдельном настраиваемом бинде (по умолчанию H).
- В колесе выбирается сначала онлайн-игрок из отслеживаемых ников, затем его собственная сохранённая фраза.
- Добавлена пагинация колеса для списков длиннее восьми элементов.
- Автоматические приветствия вынесены в отдельную опцию.
- Добавлен кеш уже поприветствованных игроков в рамках серверной сессии: TAB hide/show не вызывает повторную отправку.
- Настройки старых версий мигрируют без потери сохранённых ников и фраз.


# GreetMate 2.0.1

- Добавлено редактирование ранее сохранённых персональных приветствий.
- Нажатие на фразу загружает её в поле редактора; кнопка «Сохранить» обновляет именно её, а не создаёт копию.
- Добавлена отмена редактирования.
- Исправлено вертикальное выравнивание текста в главном GUI: подписи, строки и кнопки центрируются по высоте своих элементов.
